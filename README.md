# NORA IS SKIING

iSKI 認證雙板教練 **Nora** 的滑雪課程介紹頁。

## 內容

- **認識教練**：Nora 教練自我介紹（加拿大 CSIA 一級認證）
- **板型選擇**：雙板 Ski vs 單板 Snowboard 入門指南
- **地點介紹**：越後湯澤、北海道滑雪簡介
- **課程型態**：iSKI 私人課／團體課方案，與獨立教練推薦

## 技術

純 HTML + CSS + JavaScript 靜態網頁，無框架，設定為 4 頁翻頁式瀏覽（支援手機捲動）。

## 使用

直接開啟 `index.html`，或部署到任何靜態網站空間。
